A Map::Tube implementation for the German Rhein/Ruhr area U- and S-Bahn and tram maps.

This module allows to find the shortest route between any two given tube
stations in the Rhein/Ruhr area of Germany, including Düsseldorf and the Ruhrgebiet.
Tube, tram, S-Bahn and Schwebebahn lines are covered.

All interesting methods are provided by the role L<Map::Tube>.

To build this module, use the classical steps:

* perl Makefile.PL
* make
* make test
* make install

(If you are using Srawberry Perl under Windows, you may want to replace "make"
with "gmake".)
